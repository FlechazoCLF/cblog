# 厨艺



## 蔬菜焯水

1、水开加入盐和少量油，彩椒、芦笋、西兰花、胡萝卜切丝、菠菜焯水。

2、过冷水后控干水分。

## 胡萝卜、菠菜凉拌

1、加入生抽、醋、盐、橄榄油和白芝麻拌匀。
