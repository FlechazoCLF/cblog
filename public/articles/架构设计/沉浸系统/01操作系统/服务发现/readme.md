这里的想法呢就是所有的服务都是动态发现的

这里统一管理
当一个服务需要另一个服务时，
会来这里进行查询，如果有就申请使用，如果没有就请求发现服务，并登记使用请求

在服务发现这里收到一个新的服务时，会遍历去回调服务请求列表

关联性分为3大类：存在性关联，功能性关联，事件类关联。
存在性关联可以存储在对象中
功能性关联，事件性关联可以在线程中处理

考虑各个服务的负载均衡

其他模块申请服务之后，服务会将使用服务的用户的对象加入使用列表中
每次访问服务都会进行权限认证

一个服务层，这里管理了所有服务，其他软件都需要从这里拿到服务的接口
